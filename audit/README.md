# Relatório de Auditoria

Esta pasta reúne os relatórios de auditoria de segurança dos contratos deste repositório.

O relatório será adicionado aqui quando entregue pelo auditor (PDF e/ou markdown), junto de:

- Escopo e commit auditado
- Achados por severidade (Critical / High / Medium / Low / Informational)
- Status de remediação de cada achado
